# 🍎 Luna Bank — Установка на iPhone (полная инструкция)

## Что нужно:
- ✅ Mac (MacBook, iMac, Mac Mini — любой)
- ✅ iPhone
- ✅ USB кабель (Lightning или USB-C)
- ✅ Apple ID (тот же что на iPhone, обычный бесплатный)
- ✅ Интернет

## ⏱ Время: 
- Первый раз: ~1 час (из них 40 мин — скачивание Xcode)
- Потом: 5 минут

---

## ШАГ 1: Скачай Xcode (если ещё нет)

1. На Mac открой **App Store** (синяя иконка с буквой A)
2. В поиске набери **Xcode**
3. Нажми **Установить** (бесплатно, ~12 ГБ — будет скачиваться 20-40 мин)
4. Когда скачается — **открой Xcode** один раз
5. Появится окно "Install additional components" → нажми **Install**
6. Появится лицензия → нажми **Agree**
7. Закрой Xcode

> ⚠️ Если Xcode уже установлен — пропусти этот шаг

---

## ШАГ 2: Скачай Node.js (если ещё нет)

1. Открой браузер → https://nodejs.org
2. Нажми на зелёную кнопку **LTS** (скачается .pkg файл)
3. Открой скачанный файл → Next → Next → Install → Done

> Проверить: открой Terminal → набери `node -v` → должна показать версию

---

## ШАГ 3: Открой Terminal

1. Нажми **Cmd + Пробел** (откроется Spotlight)
2. Набери **Terminal**
3. Нажми **Enter**

Откроется чёрное/белое окно — это терминал. Сюда будем вставлять команды.

---

## ШАГ 4: Скачай проект

Скопируй ЭТУ СТРОКУ целиком и вставь в Terminal (Cmd+V), нажми Enter:

```
cd ~/Desktop && git clone https://github.com/Nikita00NS/luna-bank-app.git && cd luna-bank-app && npm install
```

⏳ Подожди 1-2 минуты пока установятся пакеты.

---

## ШАГ 5: Собери проект

Скопируй и вставь:

```
npm run build && npx cap sync ios
```

⏳ Подожди ~30 секунд.

---

## ШАГ 6: Установи CocoaPods

Скопируй и вставь:

```
sudo gem install cocoapods
```

Введи пароль от Mac (символы не будут видны — это нормально), нажми Enter.

Потом:

```
cd ios/App && pod install && cd ../..
```

⏳ Подожди 1-2 минуты.

---

## ШАГ 7: Открой проект в Xcode

Скопируй и вставь:

```
npx cap open ios
```

🎉 Откроется Xcode с проектом Luna Bank!

---

## ШАГ 8: Настрой подпись (одноразово)

В Xcode:

1. **Слева** в боковой панели нажми на **App** (самый верхний пункт, синяя иконка)
2. В центре экрана выбери вкладку **Signing & Capabilities**
3. Поставь галочку ✅ **Automatically manage signing**
4. В поле **Team** нажми выпадающее меню:
   - Если видишь свой Apple ID → выбери его
   - Если пусто → нажми **Add Account...**
     - Войди своим Apple ID (тот же что на iPhone)
     - Нажми **Next** → Apple ID появится в списке → выбери его
5. В поле **Bundle Identifier** должно быть: `app.lunabank.crypto`
   - Если Xcode ругается "Failed to register" → измени на `app.lunabank.crypto.ТВОЕИМЯ` (например `app.lunabank.crypto.nikita`)

---

## ШАГ 9: Подключи iPhone

1. Возьми USB кабель
2. Подключи iPhone к Mac
3. На iPhone появится "Доверять этому компьютеру?" → нажми **Доверять** → введи пароль iPhone
4. В Xcode **вверху** (рядом с кнопкой ▶️) нажми на выпадающее меню устройств
5. Выбери свой iPhone (он будет в списке с именем, например "iPhone Никиты")

> ⚠️ Если iPhone не появляется — отключи и подключи кабель снова

---

## ШАГ 10: Запусти приложение! 🚀

1. Нажми кнопку **▶️ (Play)** в левом верхнем углу Xcode
2. Xcode начнёт компилировать (~1-2 минуты первый раз)
3. На iPhone появится запрос — **пока не открывай приложение!**

---

## ШАГ 11: Доверься разработчику (одноразово)

На iPhone:

1. Откройся **Настройки**
2. Перейди в **Основные**
3. Прокрути вниз → **VPN и управление устройствами** (или "Профили и управление устройствами")
4. Нажми на свой Apple ID (email)
5. Нажми **Доверять "Apple Development: ТВОЙ@EMAIL"**
6. Нажми **Доверять**

---

## ШАГ 12: Готово! 🎉

Теперь на iPhone появилась иконка **Luna Bank**! 
Нажми на неё — приложение откроется!

---

## ❓ Частые проблемы

### "Signing for App requires a development team"
→ Вернись к Шагу 8, добавь Apple ID

### "Unable to install App" 
→ На iPhone: Настройки → Основные → VPN и управление устройствами → Доверять

### "Device is busy: Preparing debugger support"
→ Подожди 1-2 минуты, iPhone готовится к разработке (первый раз)

### "The device is not available"
→ Разблокируй iPhone и нажми "Доверять компьютеру"

### "Build Failed" с ошибкой про Pod
→ В Terminal выполни:
```
cd ~/Desktop/luna-bank-app/ios/App && pod install && cd ../..
npx cap open ios
```

### Приложение пропало через 7 дней
→ Это ограничение бесплатного Apple ID. Подключи iPhone к Mac и нажми ▶️ снова (30 секунд).

```
npx cap sync ios
npx cap open ios
```

Потом в Xcode нажми ▶️ — обновлённое приложение установится на iPhone.
