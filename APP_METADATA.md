## Полное описание
```
🌙 Luna Bank — крипто-финансовая экосистема

Управляйте криптовалютами как профессионал:

💎 Крипто-кошелёк
• Подключение TON Connect (Tonkeeper, MyTonWallet)
• Реальные балансы из блокчейна
• Все jetton-токены (USDT, HMSTR, tsTON и другие)
• Отправка TON прямо из приложения
• Крипто-портфель с ценами CoinGecko

🏦 Банкинг
• Открытие счетов с электронной подписью
• Переводы по телефону, username, QR-коду
• Платежи (связь, ЖКХ, игры, интернет)
• Виртуальные карты
• P2P биржа (купля/продажа за рубли)

🛡️ Безопасность
• PIN-код + биометрия (Face ID / Touch ID)
• WebAuthn аутентификация
• KYC верификация
• 2FA через Telegram

🤖 AI & Bot
• AI-ассистент (Llama 3.1)
• Telegram бот @LunaBankBot
• Push-уведомления о переводах

📊 Дополнительно
• Гарант-сервис с чатом и апелляциями
• Копилки с целями
• Реферальная программа
• 8 тем оформления
• История операций с графиками
```
